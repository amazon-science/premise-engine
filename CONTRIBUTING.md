# Contributing

This repository is a point-in-time artifact supporting the associated
scientific publication. To preserve scientific reproducibility, we do not
accept pull requests, code changes, documentation changes, feature requests,
or other contributions.

## Questions and reproducibility issues

While GitHub issues remain enabled, they may be used to ask questions or report
problems reproducing the published results. Please search existing issues
before opening a new one and include:

- The PReMISE version or commit used
- The command you ran
- The relevant configuration, with credentials and private data removed
- The observed behavior and any error messages

Reports may be discussed for the benefit of other researchers, but the
repository will not be modified in response. Once the repository is archived,
new issues cannot be opened.

## Security

Do not report security vulnerabilities through a public GitHub issue. Report
them through the
[Amazon vulnerability reporting process](https://aws.amazon.com/security/vulnerability-reporting/).
Do not include API keys, credentials, private preference data, or other
sensitive information in a public report.

## Code of Conduct

All interactions associated with this repository must follow the
[Amazon Open Source Code of Conduct](https://aws.github.io/code-of-conduct).
See the
[Code of Conduct FAQ](https://aws.github.io/code-of-conduct-faq)
for additional guidance.
